Shared database checking…

Every install — this helper and Friend Sweep Lite, on any PC — reads one shared list of silhouettes (a public GitHub gist of ) and takes what it lacks, every hour. To let this install also send what it learns and what the game rejects, save a GitHub token here, once per install:

  1. Open github.com → new token, signed in as that account.
  2. Expiration: No expiration. Tick only gist (it can not touch any repository). Press Generate token and copy it.
  3. Paste it below and press Save token. Save the same token in the other install too.
